# 업종 접미어(은행·카드·커머스·테크 …) 앞에 와도 회사 이름이 아닌 일반어 — "인터넷은행", "신용카드", "소셜커머스".
# 접미어 앞부분(어간) 전체가 이 목록의 단어 하나일 때만 회사로 보지 않는다 (detectors._industry_org).
# 끝말로 비교하지 않는다 — "…국민카드", "…투자저축은행" 같은 실제 회사 모양이 숨는다 (privacy-auditor 2차 H2).
# 고유명사로도 쓰이는 어간(가상·국민·기업·투자·모바일)은 넣지 않는다.
# 회사 이름 오탐은 같은 run 전체로 전파되므로(엔진 _replace_known), 새 오탐은 규칙을 바꾸지 말고 여기 단어를 더한다.

# 가명화 사전 (공개 목록 — 지원자 데이터 아님)

형식: 한 줄에 한 실체. `대표표기|별칭|별칭…` — 같은 줄의 표기는 같은 토큰을 받는다. `#` 은 주석.
목록은 완전하지 않다. 사전에 없는 학교·회사는 접미어 규칙(`~대학교`, `주식회사 ~`, `(주)`)과
라벨 규칙(`학교:` 등)으로 보완한다. 누락이 보이면 여기 추가한다 (공개 명칭만).

| 파일 | 범주 |
|---|---|
| universities.txt | SCHOOL |
| companies.txt | ORG |
| courses.txt | COURSE |
| surnames.txt | 사람 이름 판정용 성씨 |
| tech_terms.txt | 치환하지 않을 기술·도구 용어 (이름 오탐 방지) |

규칙
- 일반어와 겹치는 짧은 별칭(이대·외대·소마·당근·라인 등)은 넣지 않는다 — "이대로", "파이프라인" 오탐.
- `!` 접두 줄은 같은 줄에 기간이나 재직·근무·인턴·입사·퇴사 표현이 있을 때만 치환한다
  (구글·오라클처럼 회사명이자 도구명인 경우).
- 별칭 뒤에 허용 접미(학교+생, 회사+대문자 약어·클론·클라우드·Clone·Cloud)가 붙어도 같은 실체로 치환한다
  (`dictionaries.SUFFIX_ATTACHED`, 2026-11-04). 허용 목록 밖 접미("카카오톡")는 다른 단어로 본다.
- `tech_terms.txt` 의 "성씨로 시작하는 기술·측정 명사" 줄은 Kiwi 가 문맥에 따라 이름으로 잡던 것 중 자주 나오는 것만.
  이름에 쓰이지 않는 일부 외래어 음절만 `detectors._FOREIGN_SYLLABLES` 규칙이 막는다 — 이름에 있을 법한 음절로 거르면
  실제 이름이 새므로, 새 오탐 명사는 규칙을 넓히지 말고 이 목록에 단어를 더한다.
